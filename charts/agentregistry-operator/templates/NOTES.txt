Next, create a registry namespace, authentication Secret, and an AgentRegistry
resource using the repository quickstart and examples. Managed PostgreSQL needs
a default StorageClass or an explicit spec.database.storageClassName.
Inspect registry readiness with:
  kubectl get agentregistries --all-namespaces

Install only one release per cluster. Before uninstalling, delete all
AgentRegistry resources and wait for their managed children to disappear.
Helm retains the CRDs. Registry deletion retains database PVCs and user-created
Secrets, but deletes generated database credentials; back them up before deletion.
